## Project Overview
This project documents the design and analysis of our system. The three critical use cases (UC1, UC2, UC3) cover booking appointments, recording consultations, and issuing referrals.

## Repository Structure
Here is the organization of the different files and analysis documents for this submission:

* **Domain Modeling and Use Cases**
  * `domain-model.png`: Conceptual class diagram of the medical domain.
  * `use-case-diagram.png`: Global view of actors and interactions.
  * `use-cases.md`: Detailed descriptions of the critical workflows.
* **System Behavior (System-sequence-diagrams)**
  * `SSD-UC1-main.png` & `SSD-UC1-extension.png`: Scenarios for booking appointments.
  * `SSD-UC2-main.png` & `SSD-UC2-extension.png`: Scenarios for recording consultations.
  * `SSD-UC3-main.png` & `SSD-UC3-extension.png`: Scenarios for issuing referrals.
* **Contracts and Operations**
  * `System-operations.md`: List of system operations derived from the SSDs.
  * `Operation-contracts.md`: Definitions of postconditions and preconditions.

## P01 Iteration Notes
All documents were produced following the correct engineering sequence (requirements analysis, followed by domain modeling, and finally operations design).
